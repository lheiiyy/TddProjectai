🗄️ Legacy Data Setup
🗄️
Migrate Legacy SETTINGS Data
One-time import into Configuration
✓ Additive only — never edits or deletes SETTINGS/MASTER_LOG; safe to re-run

Stores, Visitors, and Purposes are now created and edited in one place: Admin → Configuration → Stores / Visitors / Purposes. The old "Store & Roster Manager" card that used to write directly to the legacy SETTINGS sheet has been removed.

Anything already sitting in the legacy SETTINGS sheet from before this change (an existing store, visitor, or purpose that was never entered through Configuration) needs to be imported once so Configuration knows about it too. This tool reads the current SETTINGS sheet and MASTER_LOG, and creates a matching Configuration entry for anything not already there — entries that already exist are skipped, so running this more than once (e.g. after fixing a typo in SETTINGS by hand) only imports what's new. Nothing in SETTINGS or MASTER_LOG is changed by this action.

🔒 Admin access required to run this tool.
